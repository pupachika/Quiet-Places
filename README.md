# Как заполнять каталог

В папке три вещи:

- `index.html` - сам сайт. Его трогать не нужно.
- `places.js` - все твои тексты и места. Редактируешь только его.
- `images/` - сюда кладёшь фотографии.

## Добавить место за 4 шага

1. Положи фото в папку `images/`. Имя файла латиницей, без пробелов: `lake-1.jpg`.
2. Открой `places.js` в любом текстовом редакторе (Блокнот, VS Code).
3. Скопируй один блок `{ ... }` из списка `PLACES`, вставь его в начало списка и поставь после него запятую.
4. Замени тексты и имя файла в `image`. Сохрани файл и обнови страницу в браузере.

Пример готового блока:

```js
{
  title: "Lake Example",
  category: "Water",
  location: "Region, Country",
  season: "June to September",
  image: "images/lake-1.jpg",
  images: ["images/lake-2.jpg", "images/lake-3.jpg"],
  description: `Первый абзац.

Второй абзац после пустой строки.`,
  tip: "Приезжай рано утром, пока нет людей.",
  tags: ["lake", "swimming"],
  map: "https://maps.google.com/..."
},
```

## Что значит каждое поле

| Поле | Зачем | Обязательно |
|---|---|---|
| `title` | название | да |
| `category` | по категориям сайт сам делает кнопки-фильтры | нет |
| `location` | где находится | нет |
| `season` | лучшее время для поездки | нет |
| `image` | главное фото на карточке | нет |
| `images` | дополнительные фото в открытой карточке | нет |
| `description` | текст, пустая строка делает новый абзац | нет |
| `tip` | короткий практический совет | нет |
| `tags` | ключевые слова, по ним работает поиск | нет |
| `map` | ссылка на карту, должна начинаться с `https://` | нет |
| `id` | адрес места на сайте, латиницей. Если не писать, создаётся из названия | нет |

Если поле не нужно, просто удали всю строку.

## Частые ошибки

- Забытая запятая между блоками `{ }`. Сайт при этом станет пустым.
- Кавычки внутри текста. Если в описании есть `"`, используй обратные кавычки `` ` `` вокруг текста, как в примере.
- Неверное имя файла фото. Тогда на карточке будет зелёная заглушка. Проверь регистр букв: `Lake.jpg` и `lake.jpg` разные имена.

## Фото

- Формат JPG, ширина 1200-1600 px, вес до 300-400 КБ. Так страница открывается быстро.
- Сжать фото без потери вида можно бесплатно на squoosh.app.
- Вертикальные и горизонтальные фото вперемешку смотрятся нормально: карточки сами подстраиваются по высоте.

## Как выложить сайт в интернет бесплатно

Нужна вся папка целиком (`index.html`, `places.js`, `images/`).

- **Netlify Drop**: открой app.netlify.com/drop и перетащи папку в окно. Сайт сразу получит адрес.
- **GitHub Pages**: создай репозиторий, загрузи файлы, в Settings > Pages включи публикацию.

Чтобы обновить сайт, замени файлы и загрузи папку заново.

## Проверка перед публикацией

Открой `index.html` двойным кликом. Если страница пустая, значит в `places.js` ошибка, чаще всего запятая или кавычка. Нажми F12, вкладка Console покажет строку с ошибкой.
